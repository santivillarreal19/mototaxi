# Mototaxi v1 — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA instalable en iPhone para que el dueño de motos registre pagos y gastos por moto, confirme cada pago al encargado por WhatsApp y vea el neto por moto y general.

**Architecture:** SPA en React + Vite + TypeScript, servida como PWA desde Cloudflare Pages. Los datos viven en Supabase (Auth + Postgres con RLS por dueño). La lógica de negocio es pura (`src/lib/`) y se prueba con Vitest. El acceso a datos está aislado en `src/data/` y las pantallas solo combinan ambas capas.

**Tech Stack:** Node 22 · React 18.3.1 · react-router-dom 6.28.0 · @supabase/supabase-js 2.47.10 · Vite 5.4.11 · Vitest 2.1.8 · TypeScript 5.7.2 · vite-plugin-pwa 0.21.1 · @vite-pwa/assets-generator 0.2.6 · Supabase CLI (vía `npx supabase`)

**Spec:** [docs/superpowers/specs/2026-10-15-mototaxi-design.md](../specs/2026-10-15-mototaxi-design.md)

## Global Constraints

- Montos: enteros en pesos colombianos, sin decimales. Se muestran como `$35.000` (punto de miles; los negativos como `-$5.000`).
- Fechas: se guardan como `YYYY-MM-DD`. "Hoy" se calcula en zona `America/Bogota`. Se muestran como `dd/mm/aaaa`.
- Teléfono del encargado: se guarda como `57` + 10 dígitos que empiezan en `3` (regex `^573[0-9]{9}$`).
- Placa: se guarda en mayúsculas, solo letras y números, de 5 a 7 caracteres, con al menos una letra y un dígito.
- Texto exacto del WhatsApp: `Hola [nombre], se registró tu pago de alquiler de la moto [placa] del día [dd/mm/aaaa] por $[monto]. ¡Gracias!`
- Enlace: `https://wa.me/<telefono>?text=<encodeURIComponent(texto)>`. Se abre **solo desde un toque del usuario** (un `<a>`), nunca de forma automática.
- Editar un pago **no** reenvía el mensaje. Las motos se archivan, no se borran.
- El neto general **incluye** los movimientos de motos archivadas (es plata que sí entró o salió). Las tarjetas por moto del inicio muestran solo las motos activas.
- UI en español. Inputs con `font-size` ≥ 16px (evita el zoom automático de iOS). Áreas táctiles ≥ 44px.
- Todo archivo de código no trivial empieza con un docstring de módulo en español: qué hace, cómo se usa y notas no obvias.
- El "lint" del CI es `tsc` (typecheck estricto). No se agrega ESLint en la v1.
- Commits: los hace Claude (proyecto de cliente propio de Santiago), con mensaje en español y terminando en `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Variables `.env`: `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY`. `.env` y `.env.*.local` nunca se commitean.

## Review Focus

1. **Más de 1000 movimientos con el período "Todo"** (unos 3 años con una moto): PostgREST devuelve como máximo 1000 filas por consulta, así que el total quedaría corto sin avisar. Se espera que el total sume todas las filas → `paginar` (Task 7) con test de 2500 filas.
2. **Registrar un pago de noche en Colombia** (después de las 7 pm ya es el día siguiente en UTC): se espera que la fecha por defecto sea el día de Colombia → test de `hoyISO` a las 21:00 de Bogotá (Task 2).
3. **Montos pegados o escritos con `$`, puntos, espacios o coma decimal** (`$ 35.000`, `35.000,50`): se espera que se lean como 35000, no como 35 ni como 3500050 → tests de `parsearPesos` (Task 1).
4. **Teléfono escrito con `+57`, espacios, guiones o paréntesis, o un número fijo**: se espera que se normalice o se rechace con un mensaje claro, nunca que se guarde un número al que WhatsApp no llega → tests de `normalizarTelefono` (Task 3).
5. **Safari sin señal** (el error de iOS es `"Load failed"`, no `"Failed to fetch"`): se espera "No hay conexión" y que el formulario conserve lo escrito → tests de `aErrorApp` (Task 7). Los formularios no se limpian en el `catch` (Tasks 8 y 10).

```ts
/**
 * Formato y lectura de montos en pesos colombianos (enteros, sin decimales).
 *
 * - formatearPesos(35000) → "$35.000"; formatearMiles(35000) → "35.000" (para inputs).
 * - parsearPesos acepta lo que el usuario escriba o pegue ("$ 35.000", "35.000,50")
 *   y devuelve el entero, o null si no hay dígitos.
 * Nota: el formato se arma a mano (no con Intl) para que sea idéntico en Safari, en Node
 * y en los tests; Intl es-CO inserta un espacio duro después del $.
 */

export function formatearMiles(n: number): string {
  return Math.abs(Math.trunc(n))
    .toString()
    .replace(/\B(?=(\d{3})+(?!\d))/g, '.');
}

export function formatearPesos(n: number): string {
  return `${n < 0 ? '-' : ''}$${formatearMiles(n)}`;
}

export function parsearPesos(texto: string): number | null {
  // Una coma seguida de 1–2 dígitos al final son centavos: se descartan.
  const sinCentavos = texto.trim().replace(/,\d{1,2}$/, '');
  const digitos = sinCentavos.replace(/\D/g, '');
  return digitos === '' ? null : Number(digitos);
}
```

`src/lib/fechas.ts`:
```ts
/**
 * Fechas del negocio: "hoy" en Colombia, formato dd/mm/aaaa y rangos de período.
 *
 * - Las fechas viajan como texto ISO 'YYYY-MM-DD' (igual que la columna `date` de Postgres),
 *   así que se comparan como strings y no hay líos de zona horaria al guardarlas.
 * - hoyISO usa America/Bogota: a las 9 pm de Colombia ya es el día siguiente en UTC, y el
 *   pago debe quedar en el día local.
 */

export const ZONA_HORARIA = 'America/Bogota';

export type Periodo = 'mes' | 'mes_anterior' | 'todo';

export const PERIODOS: { valor: Periodo; etiqueta: string }[] = [
  { valor: 'mes', etiqueta: 'Este mes' },
  { valor: 'mes_anterior', etiqueta: 'Mes anterior' },
  { valor: 'todo', etiqueta: 'Todo' },
];

export function esPeriodo(v: unknown): v is Periodo {
  return PERIODOS.some((p) => p.valor === v);
}

const formatoDia = new Intl.DateTimeFormat('es-CO', {
  timeZone: ZONA_HORARIA,
  year: 'numeric',
  month: '2-digit',
  day: '2-digit',
});

export function hoyISO(ahora: Date = new Date()): string {
  const partes = formatoDia.formatToParts(ahora);
  const valor = (tipo: Intl.DateTimeFormatPartTypes) => partes.find((p) => p.type === tipo)!.value;
  return `${valor('year')}-${valor('month')}-${valor('day')}`;
}

export function formatearFecha(iso: string): string {
  const [anio, mes, dia] = iso.split('-');
  return `${dia}/${mes}/${anio}`;
}

const dosDigitos = (n: number) => String(n).padStart(2, '0');

/** Último día del mes; `mes` va de 1 a 12. El día 0 del mes siguiente es el último de este. */
function ultimoDia(anio: number, mes: number): number {
  return new Date(Date.UTC(anio, mes, 0)).getUTCDate();
}

export function rangoPeriodo(periodo: Periodo, hoy: string): { desde: string | null; hasta: string | null } {
  if (periodo === 'todo') return { desde: null, hasta: null };
  let [anio, mes] = hoy.split('-').map(Number);
  if (periodo === 'mes_anterior') {
    mes -= 1;
    if (mes === 0) {
      mes = 12;
      anio -= 1;
    }
  }
  const prefijo = `${anio}-${dosDigitos(mes)}`;
  return { desde: `${prefijo}-01`, hasta: `${prefijo}-${dosDigitos(ultimoDia(anio, mes))}` };
}
```

```ts
 *   dígitos, solo para celulares colombianos (empiezan en 3). Los fijos se rechazan porque

  );
}
```

```ts
/**
 * Validaciones de formularios. Cada validar* devuelve el mensaje de error para mostrar
 * junto al campo, o null si el valor es válido.
 *
 * Nota: las reglas de placa y teléfono coinciden con los CHECK de la migración
 * supabase/migrations/20261015120000_esquema_inicial.sql; si cambian, cambiar ambas.

import { normalizarTelefono } from './whatsapp';

export const MONTO_MAXIMO = 50_000_000;

export function normalizarPlaca(texto: string): string {
  return texto.toUpperCase().replace(/[^A-Z0-9]/g, '');
}

export function validarPlaca(placa: string): string | null {
  if (placa === '') return 'Escribe la placa';
  if (!/^(?=.*[A-Z])(?=.*\d)[A-Z0-9]{5,7}$/.test(placa)) {
    return 'Placa inválida: usa letras y números, ej. ABC12D';
  }
  return null;
}

export function validarMonto(n: number | null): string | null {
  if (n === null) return 'Escribe el monto';
  if (n <= 0) return 'El monto debe ser mayor a $0';
  if (n > MONTO_MAXIMO) return 'El monto parece demasiado alto, revísalo';
  return null;
}

export function validarFecha(iso: string, hoy: string): string | null {
  if (iso === '') return 'Elige la fecha';
  if (iso > hoy) return 'La fecha no puede ser futura';
  return null;
}

export function validarTelefono(texto: string): string | null {
  return normalizarTelefono(texto) ? null : 'Escribe un celular colombiano de 10 dígitos (ej. 300 123 4567)';
}

export function validarTexto(texto: string, queFalta: string): string | null {
  return texto.trim() === '' ? `Escribe ${queFalta}` : null;
}
```

```ts
/**
 * Totales de dinero: ingresos (pagos), gastos y neto (ingresos − gastos).
 *
 * Los totales nunca se guardan en la base: se calculan siempre a partir de los movimientos
 * consultados, así no se desincronizan. El llamador debe pasar TODOS los movimientos del
 * período (ver data/paginar.ts: PostgREST corta en 1000 filas).
 */
import type { Movimiento } from './tipos';

export interface Totales {
  ingresos: number;
  gastos: number;
  neto: number;
}

export const TOTALES_VACIOS: Totales = { ingresos: 0, gastos: 0, neto: 0 };

function sumar(t: Totales, m: Pick<Movimiento, 'tipo' | 'monto'>): Totales {
  const ingresos = t.ingresos + (m.tipo === 'pago' ? m.monto : 0);
  const gastos = t.gastos + (m.tipo === 'gasto' ? m.monto : 0);
  return { ingresos, gastos, neto: ingresos - gastos };
}

export function calcularTotales(movs: Pick<Movimiento, 'tipo' | 'monto'>[]): Totales {
  return movs.reduce(sumar, TOTALES_VACIOS);
}

export function totalesPorMoto(movs: Pick<Movimiento, 'moto_id' | 'tipo' | 'monto'>[]): Map<string, Totales> {
  const porMoto = new Map<string, Totales>();
  for (const m of movs) porMoto.set(m.moto_id, sumar(porMoto.get(m.moto_id) ?? TOTALES_VACIOS, m));
  return porMoto;
}
```

```sql
-- Cada fila pertenece a un usuario (user_id) y solo él la ve o la modifica.

  id                 uuid primary key default gen_random_uuid(),
  user_id            uuid not null default auth.uid() references auth.users (id) on delete cascade,
  placa              text not null check (placa ~ '^[A-Z0-9]{5,7}$'),
  alias              text,
  tarifa_diaria      integer not null check (tarifa_diaria > 0),
  encargado_nombre   text not null check (length(trim(encargado_nombre)) > 0),
  encargado_telefono text not null check (encargado_telefono ~ '^573[0-9]{9}$'),
  archivada          boolean not null default false,
  created_at         timestamptz not null default now(),
  unique (user_id, placa)
);

create table public.movimientos (
  id         uuid primary key default gen_random_uuid(),
  user_id    uuid not null default auth.uid() references auth.users (id) on delete cascade,
  moto_id    uuid not null references public.motos (id) on delete restrict,
  tipo       text not null check (tipo in ('pago', 'gasto')),
  fecha      date not null,
  monto      integer not null check (monto > 0),
  categoria  text check (categoria in ('mantenimiento', 'repuestos', 'combustible', 'soat_impuestos', 'otro')),
  nota       text,
  created_at timestamptz not null default now(),
  constraint categoria_segun_tipo check (
    (tipo = 'gasto' and categoria is not null) or (tipo = 'pago' and categoria is null)
  )
);

create index movimientos_moto_fecha_idx on public.movimientos (moto_id, fecha);

alter table public.motos enable row level security;
alter table public.movimientos enable row level security;

create policy motos_del_dueno on public.motos
  for all to authenticated
  using (user_id = (select auth.uid()))
  with check (user_id = (select auth.uid()));

-- Además del dueño, el movimiento debe apuntar a una moto del mismo dueño.
create policy movimientos_del_dueno on public.movimientos
  for all to authenticated
  using (user_id = (select auth.uid()))
  with check (
    user_id = (select auth.uid())
    and exists (select 1 from public.motos m where m.id = moto_id and m.user_id = (select auth.uid()))
  );
```

```ts
/**
 * Trae TODAS las filas de una consulta, página por página.
 *
 * PostgREST (Supabase) devuelve como máximo 1000 filas por consulta y no avisa cuando corta.
 * Con el período "Todo" una moto pasa de 1000 movimientos en unos 3 años y los totales
 * quedarían cortos. Uso: paginar((desde, hasta) => consulta.range(desde, hasta)).
 * La consulta debe tener un orden estable (incluir `id` como desempate).
 */
export async function paginar<T>(
  traerPagina: (desde: number, hasta: number) => Promise<T[]>,
  tamano = 1000,
): Promise<T[]> {
  const todo: T[] = [];
  for (let desde = 0; ; desde += tamano) {
    const pagina = await traerPagina(desde, desde + tamano - 1);
    todo.push(...pagina);
    if (pagina.length < tamano) return todo;
  }
}
```

`src/data/errores.ts`:
```ts
/**
 * Traduce cualquier error (red, Postgres, PostgREST, Auth) a un ErrorApp con un mensaje
 * entendible para el cliente y un `tipo` con el que la UI decide qué hacer
 * (p. ej. 'sesion' → cerrar sesión y volver al login; 'duplicado' → marcar el campo).
 *
 * Nota: Safari reporta la falta de red como "Load failed" y Chrome como "Failed to fetch".
 * supabase-js a veces devuelve objetos planos {code, message}, no instancias de Error.
 */

export type TipoError = 'sin_conexion' | 'duplicado' | 'sesion' | 'credenciales' | 'no_encontrado' | 'desconocido';

const MENSAJES: Record<TipoError, string> = {
  sin_conexion: 'No hay conexión a internet. No se guardó: revisa la señal e intenta de nuevo.',
  duplicado: 'Ya existe un registro igual.',
  sesion: 'Tu sesión venció. Vuelve a iniciar sesión.',
  credenciales: 'Correo o contraseña incorrectos.',
  no_encontrado: 'No se encontró el registro.',
  desconocido: 'Algo salió mal. Intenta de nuevo.',
};

export class ErrorApp extends Error {
  readonly tipo: TipoError;

  constructor(tipo: TipoError, mensaje: string = MENSAJES[tipo]) {
    super(mensaje);
    this.name = 'ErrorApp';
    this.tipo = tipo;
  }
}

function navegadorEnLinea(): boolean {
  return typeof navigator === 'undefined' ? true : navigator.onLine;
}

export function aErrorApp(e: unknown, enLinea: boolean = navegadorEnLinea()): ErrorApp {
  if (e instanceof ErrorApp) return e;
  const obj = (typeof e === 'object' && e !== null ? e : {}) as { code?: unknown; message?: unknown };
  const codigo = String(obj.code ?? '');
  const texto = String(obj.message ?? '');

  let tipo: TipoError = 'desconocido';
  if (!enLinea || /failed to fetch|load failed|network/i.test(texto)) tipo = 'sin_conexion';
  else if (codigo === '23505') tipo = 'duplicado';
  else if (codigo === 'PGRST301' || /jwt/i.test(texto)) tipo = 'sesion';
  else if (codigo === 'invalid_credentials' || /invalid login credentials/i.test(texto)) tipo = 'credenciales';
  else if (codigo === 'PGRST116') tipo = 'no_encontrado';

  if (tipo === 'desconocido') console.error(e);
  return new ErrorApp(tipo);
}
```

```ts
import type { Moto, MotoNueva } from '../lib/tipos';
```

```ts
/**
 * Consultas de la tabla `movimientos` (pagos y gastos).
 * listarMovimientos pagina para no perder filas por el tope de 1000 de PostgREST
 * (ver paginar.ts). El orden es fecha desc → created_at desc → id, estable para paginar.
 */
import type { Movimiento, MovimientoNuevo } from '../lib/tipos';
import { paginar } from './paginar';
import { supabase } from './supabase';

const COLUMNAS = 'id, moto_id, tipo, fecha, monto, categoria, nota, created_at';

export async function listarMovimientos(f: {
  motoId?: string;
  desde: string | null;
  hasta: string | null;
}): Promise<Movimiento[]> {
  return paginar(async (inicio, fin) => {
    let consulta = supabase
      .from('movimientos')
      .select(COLUMNAS)
      .order('fecha', { ascending: false })
      .order('created_at', { ascending: false })
      .order('id');
    if (f.motoId) consulta = consulta.eq('moto_id', f.motoId);
    if (f.desde) consulta = consulta.gte('fecha', f.desde);
    if (f.hasta) consulta = consulta.lte('fecha', f.hasta);
    const { data, error } = await consulta.range(inicio, fin);
    if (error) throw error;
    return data as Movimiento[];
  });
}

export async function obtenerMovimiento(id: string): Promise<Movimiento> {
  const { data, error } = await supabase.from('movimientos').select(COLUMNAS).eq('id', id).single();
  if (error) throw error;
  return data as Movimiento;
}

export async function crearMovimiento(m: MovimientoNuevo): Promise<Movimiento> {
  const { data, error } = await supabase.from('movimientos').insert(m).select(COLUMNAS).single();
  if (error) throw error;
  return data as Movimiento;
}

export async function actualizarMovimiento(id: string, cambios: Partial<MovimientoNuevo>): Promise<Movimiento> {
  const { data, error } = await supabase.from('movimientos').update(cambios).eq('id', id).select(COLUMNAS).single();
  if (error) throw error;
  return data as Movimiento;
}

export async function eliminarMovimiento(id: string): Promise<void> {
  const { error } = await supabase.from('movimientos').delete().eq('id', id);
  if (error) throw error;
}
```

```ts
/**
 * Carga datos asíncronos para una pantalla y expone { datos, error, cargando, recargar }.
 * Traduce el error con aErrorApp. Si la sesión venció, cierra sesión: RutaProtegida
 * lleva entonces al login y, al volver a entrar, regresa a la misma pantalla.
 * Ignora respuestas viejas si las dependencias cambian antes de que llegue la anterior.
 */
import { useEffect, useState } from 'react';
import { aErrorApp } from '../data/errores';
import { supabase } from '../data/supabase';

interface Estado<T> {
  datos: T | null;
  error: string | null;
  cargando: boolean;
}

export function useDatos<T>(cargar: () => Promise<T>, deps: unknown[]) {
  const [estado, setEstado] = useState<Estado<T>>({ datos: null, error: null, cargando: true });
  const [version, setVersion] = useState(0);

  useEffect(() => {
    let vigente = true;
    setEstado((e) => ({ ...e, cargando: true, error: null }));
    cargar()
      .then((datos) => {
        if (vigente) setEstado({ datos, error: null, cargando: false });
      })
      .catch((e: unknown) => {
        if (!vigente) return;
        const err = aErrorApp(e);
        if (err.tipo === 'sesion') void supabase.auth.signOut();
        setEstado((anterior) => ({ datos: anterior.datos, error: err.message, cargando: false }));
      });
    return () => {
      vigente = false;
    };
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [...deps, version]);

  return { ...estado, recargar: () => setVersion((v) => v + 1) };
}
```

```tsx
/**

 * guardada en el dispositivo (evita mandar al login por un instante al abrir la app).
 * Uso: envolver la app en <SesionProvider> y leer con useSesion().

import type { Session } from '@supabase/supabase-js';
import { createContext, useContext, useEffect, useState, type ReactNode } from 'react';

const Contexto = createContext<{ sesion: Session | null; cargando: boolean }>({ sesion: null, cargando: true });

export function SesionProvider({ children }: { children: ReactNode }) {
  const [sesion, setSesion] = useState<Session | null>(null);
  const [cargando, setCargando] = useState(true);

  useEffect(() => {
    supabase.auth.getSession().then(({ data }) => {
      setSesion(data.session);
      setCargando(false);

    const { data } = supabase.auth.onAuthStateChange((_evento, nueva) => {
      setSesion(nueva);
      setCargando(false);
    });
    return () => data.subscription.unsubscribe();
  }, []);

  return <Contexto.Provider value={{ sesion, cargando }}>{children}</Contexto.Provider>;
}
```

```tsx
function FormularioMoto({ existente }: { existente?: Moto }) {
  const navigate = useNavigate();
  const [placa, setPlaca] = useState(existente?.placa ?? '');
  const [alias, setAlias] = useState(existente?.alias ?? '');
  const [tarifa, setTarifa] = useState<number | null>(existente?.tarifa_diaria ?? null);
  const [nombre, setNombre] = useState(existente?.encargado_nombre ?? '');
  const [telefono, setTelefono] = useState(existente ? formatearTelefono(existente.encargado_telefono) : '');
  const [errores, setErrores] = useState<Record<string, string | null>>({});
  const [errorGeneral, setErrorGeneral] = useState<string | null>(null);
  const [guardando, setGuardando] = useState(false);

  async function guardar(e: FormEvent) {
    e.preventDefault();
    const placaLimpia = normalizarPlaca(placa);
    const nuevos = {
      placa: validarPlaca(placaLimpia),
      tarifa: validarMonto(tarifa),
      nombre: validarTexto(nombre, 'el nombre del encargado'),
      telefono: validarTelefono(telefono),
    };
    setErrores(nuevos);
    if (Object.values(nuevos).some(Boolean)) return;

    const datos: MotoNueva = {
      placa: placaLimpia,
      alias: alias.trim() || null,
      tarifa_diaria: tarifa!,
      encargado_nombre: nombre.trim(),
      encargado_telefono: normalizarTelefono(telefono)!,
    };
    setGuardando(true);
    setErrorGeneral(null);
    try {
      const moto = existente ? await actualizarMoto(existente.id, datos) : await crearMoto(datos);
      navigate(`/motos/${moto.id}`, { replace: true });
    } catch (err) {
      const app = aErrorApp(err);
      if (app.tipo === 'duplicado') setErrores((p) => ({ ...p, placa: 'Ya tienes una moto con esa placa' }));
      else setErrorGeneral(app.message);
      if (app.tipo === 'sesion') await supabase.auth.signOut();
    } finally {
      setGuardando(false);
    }
  }

  async function alternarArchivo() {
    if (!existente) return;
    const archivar = !existente.archivada;
    if (archivar && !window.confirm('¿Archivar esta moto? Su historial se conserva y deja de aparecer en el inicio.')) return;
    setGuardando(true);
    try {
      await actualizarMoto(existente.id, { archivada: archivar });
      navigate(archivar ? '/motos' : `/motos/${existente.id}`, { replace: true });
    } catch (err) {
      setErrorGeneral(aErrorApp(err).message);
      setGuardando(false);
    }
  }

  return (
    <main className="pantalla">
      <Encabezado titulo={existente ? 'Editar moto' : 'Nueva moto'} volverA={existente ? `/motos/${existente.id}` : '/motos'} />
      <form onSubmit={guardar} noValidate>
        {errorGeneral && <Aviso>{errorGeneral}</Aviso>}
        <Campo id="placa" etiqueta="Placa" error={errores.placa}>
          <input id="placa" value={placa} onChange={(e) => setPlaca(e.target.value)} autoCapitalize="characters" autoComplete="off" aria-invalid={Boolean(errores.placa)} />
        </Campo>
        <Campo id="alias" etiqueta="Alias (opcional)">
          <input id="alias" value={alias} onChange={(e) => setAlias(e.target.value)} placeholder="Ej. La roja" />
        </Campo>

        <Campo id="nombre" etiqueta="Nombre del encargado" error={errores.nombre}>
          <input id="nombre" value={nombre} onChange={(e) => setNombre(e.target.value)} autoComplete="off" aria-invalid={Boolean(errores.nombre)} />

        </Campo>
```

```ts
/**
 * Período seleccionado (este mes / mes anterior / todo), guardado en la URL (?periodo=)
 * para que se conserve al volver atrás. Un valor inválido o ausente cuenta como 'mes'.
 */
import { useSearchParams } from 'react-router-dom';
import { esPeriodo, type Periodo } from '../lib/fechas';

export function usePeriodo(): [Periodo, (p: Periodo) => void] {
  const [params, setParams] = useSearchParams();
  const crudo = params.get('periodo');
  const periodo: Periodo = esPeriodo(crudo) ? crudo : 'mes';
  const cambiar = (p: Periodo) => setParams(p === 'mes' ? {} : { periodo: p }, { replace: true });
  return [periodo, cambiar];
}
```

```tsx
 * El enlace es un <a> que toca el usuario: iOS bloquea abrir otra app por código.
 * Si WhatsApp no abre, "Copiar mensaje" deja el texto en el portapapeles; si el
 * portapapeles falla, se muestra el texto seleccionable.

import { useState } from 'react';
import { Link, useParams } from 'react-router-dom';
import { Encabezado } from '../componentes/Encabezado';
import { Aviso, Cargando } from '../componentes/Estado';

import { enlaceWhatsApp, mensajePago } from '../lib/whatsapp';

export function PagoRegistrado() {
  const { id = '' } = useParams();
  const [copiado, setCopiado] = useState<'no' | 'si' | 'fallo'>('no');
  const { datos, error, cargando } = useDatos(async () => {
    const movimiento = await obtenerMovimiento(id);
    return { movimiento, moto: await obtenerMoto(movimiento.moto_id) };

      setCopiado('si');
    } catch {
      setCopiado('fallo');

      <section className="tarjeta">
        <p className="etiqueta">Guardado</p>

        </p>

        Enviar a {moto.encargado_nombre} por WhatsApp
      </a>
      <button type="button" className="boton boton--secundario" onClick={copiar}>
        {copiado === 'si' ? 'Mensaje copiado ✓' : 'Copiar mensaje'}
      </button>
      {copiado === 'fallo' && (

          <label htmlFor="texto-manual">No se pudo copiar automáticamente. Mantén presionado para copiar:</label>

        </div>
      )}
      <Link className="boton boton--secundario" to={`/motos/${moto.id}`}>

      </Link>
```
